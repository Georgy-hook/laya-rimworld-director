# RimWorld Autopilot 0.0.5

This update focuses on the first weeks of a colony: getting people into sheltered beds, preparing for new arrivals, making useful trades, and bringing every gun into a fight when a wall blocks the current firing lane.

The Windows installer includes the updated desktop app and RIMAPI mod. Download **RimWorld-Autopilot-0.0.5-Setup.exe** below, or use the fixed-name **RimWorld-Autopilot-Installer.exe** link from the README. The first setup downloads Laya separately; the model is not bundled with the installer.

Seven observed colony runs and the focused animal-raid replay are described in [PLAYTEST_REPORT.md](../PLAYTEST_REPORT.md). The new replay showed both shooters attacking after a covered reposition, but it was not the exact two-shooter wall scenario. This remains an experimental autopilot; use a copy of a save you care about.

See [RELEASE_NOTES.md](../RELEASE_NOTES.md) for the full change list and [Quick install](../README.md#quick-install) for setup.
