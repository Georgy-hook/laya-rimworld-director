# Generated GUI artwork

These project-local PNG files were generated with the built-in ImageGen tool. Packaged applications load them locally and never depend on generation cache paths or an online image service.

## Navigation icons

```text
Style/medium: premium fancy cartoon game UI icon, softly painted 3D-like form, rounded silhouette, subtle handcrafted texture
Composition/framing: one centered compact icon, full object visible, generous transparent padding, extremely clear at 32–48 px
Lighting/mood: cyan rim light, muted violet shadows, tiny warm amber glow
Color palette: deep navy, charcoal, muted violet, cyan, small amber accents
Materials/textures: matte painted metal, soft bevels
Scene/backdrop: genuinely transparent background
Constraints: actual alpha transparency; exactly one coherent icon; no text; no letters; no logos; no trademarks; no characters; no watermark; no border; no extra objects
```
